# Candy-Gestion-Inventario
Documentación técnica del sistema de gestión de inventario y reabastecimiento de productos para Candy.

Descripción del proyecto
Candy es una empresa minorista dedicada a la comercialización de golosinas. Este proyecto propone el desarrollo de un sistema digital de gestión de inventario y reabastecimiento de productos.
El sistema permitirá registrar las ventas, actualizar automáticamente el stock, detectar productos con bajo nivel de existencias y generar alertas para facilitar la reposición de mercadería.
También permitirá integrar las áreas de Ventas, Compras y Finanzas, mejorando la organización y la toma de decisiones.

Objetivo general
Diseñar un sistema de gestión de inventario que permita controlar las existencias, registrar los movimientos de productos y optimizar el proceso de reabastecimiento.

Funcionalidades principales
-Registro de productos.
-Actualización automática del stock después de cada venta.
-Control de entradas y salidas de mercadería.
-Alertas por stock mínimo.
-Gestión de proveedores.
-Sugerencias de reposición.
-Registro de pedidos de compra.
